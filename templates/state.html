Note for officesWhat a retrieval-first pilot looks like

Agents that read whole files to find one passage are billed for every file. A local index answers "where is it" first and the agent reads only that passage. Measured on a production codebase: 16 to 47 times less read per answer; on published coding tasks: 2.7 times fewer tokens end to end. The software is open source and runs inside your own environment; nothing leaves the building.
